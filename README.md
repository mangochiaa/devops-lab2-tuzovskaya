# DevOps Lab 2 — CI/CD для Docker приложения

Репозиторий создан в рамках лабораторной работы №2 по курсу «Введение в веб технологии».

## О проекте

Это Flask-приложение в Docker, для которого настроен CI/CD пайплайн на GitHub Actions. При пуше в ветку main автоматически:
- Собирается Docker образ
- Публикуется в Docker Hub
